# stuff.arnavraja.in
An upright, paper-shaped one-bit screen after the Xerox Alto (1973). Each thing is an overlapping window with a tab: drag it, click to bring it to the front.

To add a thing: edit `_data/stuff.yml` and copy one block. It becomes a new window.

Notes are Markdown: maths in `$$...$$`, fenced code, tables. Use `note: |` for several paragraphs.
